# 🧴 HomeReminder PL — Умный учёт косметики и бытовой химии

Кроссплатформенное мобильное приложение (**Flutter**) и ИИ-сервис (**FastAPI + SQLite**) для:
1. **Автоматического ИИ-расчёта расхода** косметики и бытовой химии по свободному описанию (например: *«Гель для умывания 400 мл, умываемся вдвоём утром и вечером»* -> `8 мл/день`, хватит на `50 дней`).
2. **Локальных Push-уведомлений** (`flutter_local_notifications`), которые заранее напоминают о том, что средство заканчивается.
3. **Мониторинга цен и наличия в магазинах Польши:**
   - **Rossmann** (`rossmann.pl`)
   - **Hebe** (`hebe.pl`)
   - **Allegro** (`allegro.pl`)
   - **Ekodrogeria** (`ekodrogeria.pl`)

---

## 🚀 Быстрый запуск

### 1. Запуск Backend API (FastAPI + ИИ-оракул + Парсер магазинов Польши)
```powershell
cd D:\AI_Workspace\01_Projects\HomeReminder\backend
uv run uvicorn app.main:app --reload --port 8000
```
*Swagger UI документация и тестирование запросов будут доступны по адресу:* `http://127.0.0.1:8000/docs`
*(Опционально: скопируйте `.env.example` в `.env` и укажите бесплатный `GEMINI_API_KEY` для LLM-анализа сложных описаний; без ключа автоматически работает встроенный детерминированный ИИ-оракул расхода).*

### 2. Запуск мобильного приложения (Flutter)
```powershell
cd D:\AI_Workspace\01_Projects\HomeReminder\mobile
flutter pub get
flutter run
```
*(Приложение также поддерживает автономный офлайн-режим с локальным кэшем `SharedPreferences`, если сервер не запущен).*
